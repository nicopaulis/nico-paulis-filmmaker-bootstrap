# Integración de Bootstrap y estados interactivos

Portafolio audiovisual de Nico Paulis actualizado para la pre-entrega de Bootstrap.

## Vista local

Abrí `index.html` en el navegador. Bootstrap 5.3.8 y Google Fonts se cargan mediante CDN, por lo que se necesita conexión a Internet.

La navegación de Bootstrap está incluida en las cinco páginas. Los carruseles están en Inicio y Proyectos.
